# 선율 수집가

- 기획서: [game-design.md](game-design.md)

## 게임 아이디어
지휘자를 방향키로 좌우 이동시켜 곡의 목표 파편을 모읍니다. 목표가 아닌 파편을 세 번 받기 전에 선율 게이지를 채우면, 인간 형태를 이룬 곡 ‘무지카’를 만납니다.

스테이지 1은 비발디 「사계」 중 ‘여름’으로 해바라기를 모읍니다. 클리어하면 여름 무지카를 만나고, “다음 무지카를 만나러 가기” 버튼으로 다음 스테이지에 진입합니다. 스테이지 2는 차이콥스키 「백조의 호수」로, 불빛이 비치는 밤 호숫가에서 백조를 모읍니다. 스테이지 3은 모차르트 「작은 별 변주곡」으로, 별똥별이 흐르는 밤 들판에서 별을 모읍니다. 스테이지가 올라갈수록 아이템은 빠르게 떨어지고 목표 아이템은 더 드물게 등장하며, 무지카마다 곡의 분위기에 맞는 인사말을 건넵니다.

게임 시작 시 홈과 스테이지 선택 화면이 표시됩니다. 스테이지 1~3은 플레이할 수 있고, 스테이지 4~10은 “COMING SOON”으로 표시됩니다. 플레이 중 ESC를 누르면 일시정지 설정이 열리며, 홈·레벨 선택·조작법 이동과 사운드 볼륨 설정을 할 수 있습니다. (사운드 재생은 아직 구현되지 않았습니다.)
