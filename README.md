- 기획서: [game-design.md](game-design.md)

## 게임 아이디어
지휘자를 방향키로 좌우 이동시켜 곡의 목표 파편을 모읍니다. 목표가 아닌 파편을 세 번 받기 전에 선율 게이지를 채우면, 인간 형태를 이룬 곡 ‘무지카’를 만납니다.

스테이지 1은 비발디 「사계」 중 ‘여름’으로 해바라기를 모읍니다. 클리어하면 여름 무지카를 만나고, “다음 무지카를 만나러 가기” 버튼으로 스테이지 2에 진입합니다. 스테이지 2는 차이콥스키 「백조의 호수」로, 불빛이 비치는 밤 호숫가에서 백조를 모읍니다. 무지카마다 곡의 분위기에 맞는 인사말을 건넵니다.
