# 선율 수집가

프로그래밍 입문 수업에서 만드는 웹 게임입니다.

- 학번 / 이름: 202411839 이서경
- 플레이: https://Labi0718.github.io/my-game/
- 기획서: [game-design.md](game-design.md)

## 게임 아이디어
지휘자를 마우스로 좌우 이동시켜 곡의 목표 파편을 모읍니다. 목표가 아닌 파편을 세 번 받기 전에 선율 게이지를 채우면, 인간 형태를 이룬 곡 ‘무지카’를 만납니다.

첫 스테이지는 비발디 「사계」 중 ‘여름’이며, 해바라기가 목표 아이템입니다. 곡마다 목표 파편과 배경 분위기가 달라집니다.
