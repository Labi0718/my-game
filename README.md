## 게임 아이디어
지휘자를 방향키로 좌우 이동시켜 곡의 목표 파편을 모읍니다. 목표가 아닌 파편을 세 번 받기 전에 선율 게이지를 채우면, 인간 형태를 이룬 곡 ‘무지카’를 만납니다.

스테이지 1은 비발디 「사계」 중 ‘여름’으로 해바라기를 모읍니다. 클리어하면 여름 무지카를 만나고, “다음 무지카를 만나러 가기” 버튼으로 다음 스테이지에 진입합니다. 스테이지 2는 차이콥스키 「백조의 호수」로, 불빛이 비치는 밤 호숫가에서 백조를 모읍니다. 스테이지 3은 모차르트 「작은 별 변주곡」으로, 별똥별이 흐르는 밤 들판에서 별을 모읍니다. 스테이지 4는 엘가 「위풍당당 행진곡」으로, 왕실 홀에서 왕관을 모읍니다. 스테이지 5는 베토벤 「교향곡 5번 운명」으로, 붉은 실 장식과 거대한 시계가 있는 웅장한 오케스트라 홀에서 붉은 실을 모읍니다. 스테이지 6은 쇼팽 「환상 즉흥곡」으로, 쨍한 햇빛 아래 꽃이 무성한 들판과 꽃 아치에서 꽃을 모읍니다. 뒤쪽 스테이지일수록 아이템이 빨라지는 가운데, 스테이지 6은 꽃이 더 자주 등장하도록 조정했습니다. 무지카마다 곡의 분위기에 맞는 인사말을 건넵니다.

처음 제목 화면에서 아무 키나 누르면 이야기와 조작법 안내가 나오고, 안내 화면에서 다시 아무 키나 누르면 스테이지 1이 시작됩니다. 스테이지 1~6은 플레이할 수 있고, 스테이지 7~10은 “COMING SOON”으로 표시됩니다. 스테이지 4부터 10초가 지난 뒤 낙하 속도가 10초마다 올라갑니다. 스테이지 4는 0.5씩, 최대 9까지이며, 스테이지 5~6은 0.3씩, 최대 7.5까지입니다. 일시정지 중에는 시간이 쌓이지 않고, 다시 시작하면 난이도 시간이 초기화됩니다.

## 조작법

| 키 | 동작 |
|---|---|
| 아무 키 | 제목 화면에서 이야기 화면으로 이동, 이야기 화면에서 스테이지 1 시작 |
| ← / → | 지휘자 좌우 이동 |
| P / ESC | 일시정지/재개 |
| M | 음소거/해제 (볼륨 설정을 0으로 전환/복원) |
| R | 게임 오버 시 현재 스테이지 다시 시작 |

일시정지 메뉴에서 홈·레벨 선택·조작법 이동과 볼륨 설정을 할 수 있습니다. 사운드 재생은 아직 구현되지 않아 M 키와 볼륨 설정은 실제 소리에 영향을 주지 않습니다.

## 사용한 에셋

외부 에셋은 사용하지 않았습니다. 게임 그래픽은 Canvas 2D로 직접 그렸고, `sketch.jpg`는 기획 시안으로만 사용했습니다.

| 에셋 | 사용처 | 출처 / 라이선스 |
|---|---|---|
| Canvas 2D 그래픽 | 배경, 지휘자, 아이템, UI | `script.js`에서 직접 그림 |
| 화면 스케치 (`sketch.jpg`) | 게임 기획서의 시안 (게임 화면에는 미사용) | 저장소에 포함된 프로젝트 자료 |
| 글꼴 (Arial, Malgun Gothic, sans-serif) | 게임 화면 텍스트 | 사용자 기기의 기본 글꼴, 외부 글꼴 파일 미사용 |
| 사운드 | 미사용 | 사운드 파일 및 재생 기능 없음 |

스테이지 4에 들어가기 전에 무지개 방울의 모습과 사용법을 안내합니다. 방울을 먹으면 10초간 무적 상태가 되어 방해 아이템에 닿아도 라이프가 줄지 않으며, 지휘자 주변에 무지개빛 오라와 남은 시간이 표시됩니다. 방울은 스테이지 4에서 최대 2개, 스테이지 5에서 3개, 스테이지 6에서 시간 간격을 두고 최대 4개 등장합니다.

스테이지 5를 시작하기 전에는 날개 달린 운동화의 모습과 효과를 안내합니다. 운동화를 먹으면 10초 동안 지휘자 이동 속도가 빨라집니다. 운동화도 스테이지 5에서 3개, 스테이지 6에서 4개까지 무지개 방울과 같은 간격으로 등장합니다.

스테이지 6을 시작하기 전에는 빛나는 자석의 모습과 효과를 안내합니다. 스테이지마다 한 번 등장하는 자석을 먹으면 15초간 범위 안의 목표 아이템만 지휘자 쪽으로 끌려옵니다. 방해 아이템은 영향을 받지 않습니다.
