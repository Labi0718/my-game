# 선율 수집가

## 게임 아이디어
지휘자를 방향키로 좌우 이동시켜 곡의 목표 파편을 모읍니다. 목표가 아닌 파편을 세 번 받기 전에 선율 게이지를 채우면, 인간 형태를 이룬 곡 ‘무지카’를 만납니다.

스테이지 1은 비발디 「사계」 중 ‘여름’으로 해바라기를 모읍니다. 클리어하면 여름 무지카를 만나고, “다음 무지카를 만나러 가기” 버튼으로 다음 스테이지에 진입합니다. 스테이지 2는 차이콥스키 「백조의 호수」로, 불빛이 비치는 밤 호숫가에서 백조를 모읍니다. 스테이지 3은 모차르트 「작은 별 변주곡」으로, 별똥별이 흐르는 밤 들판에서 별을 모읍니다. 스테이지 4는 엘가 「위풍당당 행진곡」으로, 왕실 홀에서 왕관을 모읍니다. 스테이지 5는 베토벤 「교향곡 5번 운명」으로, 붉은 실 장식과 거대한 시계가 있는 웅장한 오케스트라 홀에서 붉은 실을 모읍니다. 스테이지 6은 쇼팽 「환상 즉흥곡」으로, 쨍한 햇빛 아래 꽃이 무성한 들판과 꽃 아치에서 꽃을 모읍니다. 뒤쪽 스테이지일수록 아이템이 빨라지는 가운데, 스테이지 6은 꽃이 더 자주 등장하도록 조정했습니다. 무지카마다 곡의 분위기에 맞는 인사말을 건넵니다.

게임 시작 시 홈과 스테이지 선택 화면이 표시됩니다. 스테이지 1~6은 플레이할 수 있고, 스테이지 7~10은 “COMING SOON”으로 표시됩니다. 플레이 중 ESC를 누르면 일시정지 설정이 열리며, 홈·레벨 선택·조작법 이동과 사운드 볼륨 설정을 할 수 있습니다. (사운드 재생은 아직 구현되지 않았습니다.)
