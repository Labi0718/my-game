## 게임 아이디어
선율 수집가
흘러나오는 클래식에 맞는 상징 아이템을 모아, 곡이 의인화된 친구를 만나는 게임
플레이어가 하는 일
좌우 방향키로 바구니를 움직여 현재 곡을 상징하는 아이템을 모은다. 1스테이지는 비발디 「사계」 중 ‘여름’이며, 해바라기를 받을 때마다 선율 게이지가 5% 오른다. 해바라기 20개를 모아 게이지를 100% 채우면 여름을 의인화한 캐릭터를 만난다. 눈송이·눈사람·장갑·백조·달·빨간 실·낙엽·별·박쥐·호두는 수집 대상이 아닌 방해 아이템이다.
게임이 끝나는 조건
맞는 아이템을 받을 때마다 선율 게이지가 차오르고 100%가 되면 해당 곡의 의인화 캐릭터를 만난다. 틀린 아이템을 세 번 받으면 실패한다.

- 그 이유
클래식은 저작권이 없기때문에 게임에 사용해도 저작권 문제가 없다는 것과, 2d 캐릭터를 그리는 걸 즐기는 내가 즐기면서 만들 수 있는
구조의 게임이라고 생각했기 때문에.
